## I'm riotgossip 👋

Powered by curiosity (and too much coffee).

Hey, I'm riotgossip — I build interfaces with React, Next.js, and TypeScript, and I spend a probably unreasonable amount of time thinking about how to make them faster and more accessible. TailwindCSS and Vite are my daily drivers, and I'm happiest when I'm deep in a design system, figuring out how to make components that actually feel good to use. I'm drawn to the intersection of web performance and thoughtful UI — the kind of work where shaving off layout shifts feels as satisfying as nailing the visual details.
